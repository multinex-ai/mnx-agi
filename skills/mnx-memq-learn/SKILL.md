# Memq learn

This skill follows the active host instructions and authorized task.

Read [the MemQ contract](references/MEMQ_CONTRACT.md). Select an outcome with useful evidence: a proven fix, failed approach with root cause, stable procedure, or confirmed decision. Preserve source/task references, scope, observed date, evidence state and relevant contrary cases.

Recall existing knowledge before writing a near duplicate. Update or reference a superseding record through a supported operation. Do not resubmit identical content to inflate reinforcement. Repetition is not independent verification.

Choose the supported write or learning tool that fits the purpose. Predictions remain hypotheses. Reflection and consolidation produce derived claims requiring provenance; they do not amend policy, change permissions or certify completion. Avoid mandatory sleep/reinforcement calls for trivial sessions, and budget possible writes.

Evaluate whether a proposed lesson improves representative future decisions and fails appropriately on counterexamples. Keep generalizable content separate from private specifics. Prepare shared candidates only within the task's disclosure authorization; a commons candidate is not a published commons record.

Return the useful lesson, evidence, applicability limits and actual persistence state. If the tool is absent, retain the candidate locally without pretending that learning was written remotely.
