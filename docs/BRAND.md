# Multinex brand application

The README banner and badges use the design tokens published by [Multinex](https://multinex.ai/) and its existing [compact brand mark](https://multinex.ai/brand/multinex-mark-compact.svg), reviewed October 18, 2026. The repository copy of that mark is `assets/multinex-mark.svg`.

| Token | Value | Application |
|---|---|---|
| Void | `#080C12` | Main background and badge labels |
| Raised background | `#0C1018` | Subtle panel and gradient surface |
| Multinex gold | `#FFC857` | Brand wordmark, release, and primary emphasis |
| Warm gold | `#FFD67D` | Optional highlight |
| Cyan | `#78E7EF` | MemQ, connections, and technical accents |
| Primary text | `#E8EEF2` | Titles and primary content |
| Secondary text | `#9FB0BF` | Descriptions and supporting labels |

The published font families use Sora for display and Inter for interface/body text. Repository SVGs retain local/system fallbacks and do not fetch fonts or scripts. Preserve the mark's original geometry and gold gradient. Keep text readable in both GitHub themes by giving the banner its own background.

Badges are navigation and evidence aids. Release and CI badges use live GitHub data; license and runtime badges reflect repository declarations. Do not add a passing-build badge when checks did not run, an integration badge for an unimplemented adapter, or certification, benchmark, or performance claims without supporting evidence.
