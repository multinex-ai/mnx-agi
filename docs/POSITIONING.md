# MNX-AGI positioning

## Product identity

**MNX-AGI — Recursive Agent Harness + MemQ**

**Across agents. Across sessions. Compounding knowledge.**

MNX-AGI is a model-agnostic Recursive Agent Harness paired with MemQ for persistent memory. It helps supported agents plan, act, verify, remember, and improve—carrying useful context across sessions and turning verified work into reusable knowledge.

## GitHub description

MNX-AGI is a model-agnostic Recursive Agent Harness paired with MemQ for persistent memory across supported agents and sessions—turning verified work into reusable knowledge that compounds over time.

## Short copy

Bring your models. Connect your tools. Build on what your agents learn.

MNX-AGI guides the work. MemQ carries the knowledge forward. Together, they are designed for seamless continuity across compatible agents, with explicit project boundaries and evidence-based learning.

## Wording and claim boundaries

Use “Recursive Agent Harness” for the bounded loop of recall, action, verification, checkpointing, learning, and evaluated refinement. Describe compounding as the reuse and improvement of retained knowledge. Describe broad model support as an architectural property; identify configured host support separately.

Do not describe an unconfigured app as connected, a shared namespace as a permission grant, a plan record as a lock, or the experimental gateway as system-wide enforcement. Do not claim universal compatibility, flawless memory, autonomous self-modification, model training, or measured performance gains without the matching evidence.

## ElevenLabs inspiration

Reviewed October 18, 2026. ElevenLabs' [agent platform page](https://elevenlabs.io/agents) uses “Configure, deploy and improve” and describes bringing your own model and connecting existing tools. Its [platform documentation](https://elevenlabs.io/docs/eleven-agents/overview/) groups configuration, deployment, and performance evaluation into an agent lifecycle.

MNX-AGI adapts those themes into original wording centered on a portable harness and persistent memory. These references provide positioning inspiration; they do not establish an ElevenLabs integration, partnership, endorsement, or feature equivalence. The current package does not ship an ElevenLabs adapter. Any future voice-agent integration must authenticate its memory connection and pass its own acceptance tests.
